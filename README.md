# 珠科专升本信息查询系统

免费、无需登录的静态信息查询网页。无数据库、无付费接口、无第三方字体或运行库。可部署到 GitHub Pages 或学校现有网站。

## 当前功能

- 按专业、专业号和考试科目搜索，按年份、批次、学科和考试类型筛选。
- 查看历年计划、投档、录取、最高/最低分、最高/最低排位。
- 查看2026年考试科目、前置专业限制、学制、学费、住宿费与参考书。
- 最多3个专业对比、分享专业链接、打印、下载CSV。
- 按2026年一般政策进行报考条件自查；答案仅在页面内处理，不上传或保存。
- 集中查阅学校招生简章、14份校考大纲、政策原文及原始数据图。
- 手机适配及招生宣传展示模式。

## 数据口径

当前合计143条“年份—批次—专业/方向”记录：2026年普通批53条、2025年普通批45条、2026年退役士兵批45条。

2026年普通批招生计划来自用户提供的计划图；投档表有52条，缺048音乐表演（管乐）。缺失信息保留为 null，页面显示暂无或“—”，不填0。计划、投档、录取不互相代填。

2025年音乐专业为整体口径，2026年分培养方向，系统明确提示不可直接同比。未录入2025年计划、2026年最终录取人数以及退役批录取结果。

政策自查仅适用于2026年，不能用其判断2027年或其他年度资格。退役士兵专项目前引导人工依据专项简章复核，不使用普通通道规则直接认定。具体前置专业与身体要求仍以学校审核为准。

数据整理日期：2026-10-26。原始资料索引位于 `data.json` 的 `sources`；图片校验值见 `source-integrity.json`。

## 本机使用

可直接双击 `index.html` 打开，搜索与自查不需要网络。访问官网简章和大纲仍需要网络。也可运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

## GitHub Pages 免费发布

GitHub Free 的公开仓库可使用 GitHub Pages，使用免费 `github.io` 域名即可，无需买域名。适用平台正常额度及规则；不承诺第三方平台永久政策不变或任一国内网络可达。

把 `dist` **目录内的文件**上传至公开仓库根目录，保留 `assets` 目录。进入 Settings → Pages → Deploy from a branch，选择 main 与 /(root)，保存。

仓库须保持公开以使用 GitHub Free 的免费 Pages。文件中仅包含公开招生资料，不要放置考生名单、联系方式、身份证号码或密钥。

网页支持微信浏览器的常规页面功能，不需要微信登录或SDK。电脑浏览器检查已完成，微信真机与国内移动网络需另行验收。微信如不能预览Word大纲或下载CSV，可通过菜单“在浏览器打开”使用对应功能。

## 更新数据

推荐保留本地完整工程。`build_data.py` 中的计划数组、投档表和2025年录取表为本版结构化录入来源；`charter-tables.json` 为学校2026招生简章解析表；`outlines.html` 为学校大纲入口原页面。运行：

```sh
python3 build_data.py
node verify.mjs
```

生成 `data.json`、`data.js` 与 `招生数据.csv`，随后一并上传。不要单独更改JSON而遗漏data.js，网页读取的是data.js，以兼容本机直接打开。

增添新年份时，应新增记录并保留原年份，不要覆盖旧记录；资格政策也必须按年份独立核对和实现。原图不改动，新来源另存并补充sources与校验清单。

## 核验

`verify.mjs` 检查15个资格分支、关键数据口径、缺失值、大纲映射及无第三方运行依赖。`data-validation.json` 保存条数与人数汇总，仅为核验用，页面不推算录取率。

已在浏览器检查：护理学历年数据、自查表单的社保不满足分支、320/390像素手机视口与1280像素电脑视口。更多交互检查见 `浏览器验收记录.md`。
