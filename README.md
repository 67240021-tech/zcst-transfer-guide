# 珠科专升本信息查询

在线地址：https://67240021-tech.github.io/zcst-transfer-guide/

免费、无需登录的静态查询网页；无付费接口或后台数据库。

## 功能

- 按专业名称或专业号搜索，直接查看2025录取与2026投档分数、排位和数值差。
- 搜索结果展示最低分、最低排位和招生人数；点击专业名称或“报考要求”展开科目、限制与费用。
- 手机对比表无需横向滑动；按批次、门类、考试类型筛选，每次浏览12条。
- 专业内保留2026科目、限制、学费、学制、参考书及对应校考大纲。
- 报考条件自查仅适用2026年政策，所有答案仅在本机处理。
- 14份校考大纲已转为站内网页，手机直接阅读，无需下载Word或PDF。
- 旧专业分享链接继续有效；原资料中心入口已移除。

## 数据口径

209条年份、批次、专业记录。2026录取以用户指定的李老师工作簿“2026录取情况”为准：普通批52条1848人，建档立卡批10条27人，退役士兵批39条219人，总计2094人。普通批计划仍含53个方向，退役批计划仍含45个专业；录取表未列的7项保留空值。2025年数据保持不变。

普通批已有52项数值一致，补充最终录取口径；社会工作普通批计划由81修正为80。新增录取记录按批次和专业号匹配，2025和2026专业号变化时跨年按同批次专业名称匹配。退役批音乐表演录取名称为民族或美声唱法方向，计划仍为专业整体，页面明确标注。2027拟计划未导入或发布。

页面沿用“投档人数”行名，但注释两年均按录取人数展示；原始filed字段保留历史核验，实际展示admitted字段。不同口径不计算人数差值；音乐整体与方向也不计算分数或排位差。缺失值为null而非0。政策自查仍仅适用2026。

## 文件与更新

仓库根目录直接用于GitHub Pages。index.html、style.css、app.js负责界面，comparison.js负责两年配对与差值，eligibility.js负责2026资格规则。data.js是网页读取的数据，data.json和招生数据.csv为配套资料。原始图片source-1.png至source-12.png及source-integrity.json保留。

修改后上传到main分支根目录，保持Settings → Pages为main / (root)。界面文件须同步更新并调整入口中的版本参数。更新数据时同步data.js、data.json与CSV，保留历史年度。

本机可直接打开index.html，或在仓库目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`。

GitHub Pages使用免费公开仓库及github.io域名。手机浏览器布局已检查；微信真机和国内网络访问仍需实际验证。大纲阅读页不依赖第三方预览服务；保留原文、自动编号、表格与附图。

## 本地工程维护

完整页面在dist/；GitHub发布文件/为线上根目录的平铺副本，入口favicon路径不同。修改界面文件时同步两处；outline.html、outline-reader.js、outline-data.js为站内大纲阅读页。build_data.py生成数据，并调用merge_2025_plans.py及merge_li_results.py合并2025计划和2026最终录取；更新数据后将assets/source-路径映射为线上source-路径。

运行verify.mjs和verify-outline-reader.mjs；新录取数据按李老师数据核对/验证结果.json核验，原verify-comparison.mjs为历史版本验收脚本。运行相关检查验证资格、数据口径、两年配对与大纲映射。build_outline_reader.py从大纲原文件/生成阅读数据，并在大纲核验/记录原文完整性。浏览器验收见浏览器验收记录.md。implement_mobile_reader.py、implement_comparison.py与redesign.py是单次迁移脚本，不要重复运行。
